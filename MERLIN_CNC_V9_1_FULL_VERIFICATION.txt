MERLIN CNC V9.1 FULL REPOSITORY VERIFICATION
Date: 2026-09-08

Reason for V9.1
---------------
Multiple unrelated images all reached the same "could not isolate usable geometry" error. The common failure was identified after foreground detection:
1. closed loops were passed to RDP with identical first/last endpoints, producing a zero-length baseline and collapsing valid contours;
2. the old boundary stitcher chose the first outgoing edge at bridge-created junctions, which could lose the intended contour.

Fixes
-----
- Replaced junction handling with direction-aware boundary stitching (right-turn, straight, left preference).
- Added simplifyClosedLoop(): chooses far-apart anchors, simplifies the two open arcs separately, then rejoins them.
- Added pure browser geometry self-test and a UI preflight before processing an uploaded image.
- Added cache-busting query versions for config.js, image-dxf.js and app.js so a new deploy loads the current converter.
- Retained all V9.0 high-contrast stencil, line-art rescue, Fusion-safe R12 DXF, resizer and optional fixing-hole functionality.
