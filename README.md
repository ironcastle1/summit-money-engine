# Summit Info Compiler V10

A professional global information compiler designed for routine daily use: opportunities, market-moving events, route checks, area scans, and source health.

## Deploy

Render settings:

- Build Command: `npm install --package-lock=false --no-audit --no-fund`
- Start Command: `npm start`
- Root Directory: leave blank

## Main product idea

Users open this with coffee, check what changed, identify actionable opportunities, then return throughout the day for fresh alerts and routes/area scans.
