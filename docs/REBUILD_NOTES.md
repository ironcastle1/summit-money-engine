# Rebuild notes

This rebuild changes the product from a generic money map into a security companion.

## Product focus

1. Europe-first travel security.
2. Family watch for places such as Syria and the Middle East.
3. Off-grid / resilience infrastructure around clicked places.
4. Business and money signals as supporting context, not the main product.
5. Strict data provenance.

## No fake values

The app does not pretend to have town-level crime for every country. UK local crime uses data.police.uk. Other countries use national indicators plus live event pressure unless a local feed is later connected.
