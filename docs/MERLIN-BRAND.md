# Merlin identity

The product name is **Merlin**. The approved identity depicts an elderly, severe-looking wizard studying an old book in clean black-and-white linework.

## Repository assets

- `public/assets/merlin-logo-master.png` — approved full-resolution source artwork.
- `public/assets/merlin-logo-black.png` — transparent black full logo.
- `public/assets/merlin-logo-white.png` — transparent white full logo for dark surfaces.
- `public/assets/merlin-mark-black.png` — transparent black wizard-and-book mark.
- `public/assets/merlin-mark-white.png` — transparent white wizard-and-book mark used in the application header.
- `public/icons/merlin-64.png`, `merlin-192.png`, `merlin-512.png` — browser and PWA icons.

Do not add gradients, artificial ageing, wear marks, neon colour treatments or a separate decorative element beneath the Merlin wordmark.
