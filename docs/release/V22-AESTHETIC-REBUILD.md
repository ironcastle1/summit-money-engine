# Merlin V22 aesthetic rebuild

V22 is a complete customer-interface redesign over the existing Merlin intelligence platform. It does not create a second application or discard the server, APIs, data pipelines, account system, automation, publishing, security or operations modules.

## Design system

The release introduces an obsidian-led visual language with restrained gold, cyan and status accents; serif display typography for identity; compact sans-serif operational typography; consistent elevation; stronger spacing; and a single component treatment across map controls, workspaces, tables, forms, drawers and cards.

Six themes are available and update the application shell and map together. Responsive rules cover 360-pixel mobile screens through 1920-pixel desktop displays. Navigation collapses for smaller screens without removing any principal workspace.

## Browser startup

The production shell loads one self-contained browser bundle, followed by the V22 shell enhancement. The map is exposed immediately and optional intelligence systems initialise independently with hard deadlines. A failed live connector cannot leave the complete interface behind a permanent loading panel.

## Customer workspaces

The visual system covers Map, Opportunities, Markets, Conflict, Places, Live Data, Briefings, Automation, Publishing, Customers, Security, Operations and Release. Shared styling also covers alerts, account surfaces, evidence panels, reports, logistics, hazards and overlay controls.

## Acceptance

The exact release is validated through the complete Node test suite, a rendered Chromium journey at six viewport sizes, JavaScript syntax checks, import-graph auditing and embedded-secret scanning. The GitHub delivery is reconstructed from its 20 upload ZIPs and compared by file hash to the tested source tree.
