MERLIN CNC V8.7 FULL REPOSITORY VERIFICATION
Date: 2026-09-08

PURPOSE
V8.7 builds on the Fusion-safe V8.6 DXF writer and adds:
1. automatic repair of near-closed polylines in the generated copy; and
2. optional validated wall-fixing hole placement in retained steel.

AUTO-CLOSE RULE
- Applies only to POLYLINE/LWPOLYLINE entities that are currently marked open.
- Requires at least 3 vertices.
- First/last vertex gap must be <= 0.05 mm after source-unit conversion.
- The uploaded original is never edited.
- Genuinely open contours with a larger gap are left open.
- Near-duplicate final vertices without bulge/width data are dropped before the closed flag is written, avoiding an unnecessary zero-length closing segment.

FIXING-HOLE RULES
- Optional: off by default.
- Supported layouts: 2 top-region holes or 4 corner-region holes.
- Owner must enter hole diameter, preferred edge inset, and minimum retained steel around the hole.
- MERLIN does not invent these manufacturing dimensions.
- Closed contours are flattened (including polyline bulges) into a retained-steel parity mask.
- Each proposed hole and the owner's surrounding-steel allowance must lie in retained steel.
- If the preferred anchor is empty space, MERLIN searches for the nearest valid retained-steel point.
- Requested holes are kept separated from each other.
- If all requested holes cannot be placed, no download is released.
- Added holes are written as CIRCLE entities on layer MERLIN_MOUNTING_HOLES.

RELEASE GATE RETAINED FROM V8.6
Before a generated DXF is stored/downloaded, MERLIN reparses it and requires:
1. parse succeeds;
2. output width/height match calculated dimensions within 0.08 mm;
3. entity count matches the repaired source plus added fixing holes;
4. closed contour count matches the repaired source plus added holes;
5. genuine open-contour state matches the repaired source;
6. no unsupported output entity appears.

IMPORTANT CNC DISTINCTION
A structurally valid DXF, repaired closure, and geometrically validated fixing-hole position do not by themselves prove every bridge/slot/hole is suitable for the physical plasma process. MERLIN continues to report uncalibrated machine minimum-feature rules separately and does not label the whole design cut-ready solely from file-format success.
