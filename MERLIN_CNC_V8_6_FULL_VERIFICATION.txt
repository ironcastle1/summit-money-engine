MERLIN CNC V8.6 FULL REPOSITORY VERIFICATION
Date: 2026-09-08

PURPOSE
V8.6 fixes the DXF resizer so MERLIN does not release a correctly-sized but malformed file.

CORE RESIZER CHANGES
- Resized output format: AutoCAD R12 ASCII (AC1009).
- Source LWPOLYLINE/POLYLINE is written as classic POLYLINE + VERTEX + SEQEND.
- LINE, CIRCLE and ARC are written in R12-compatible structures.
- Polyline closed/open state is preserved.
- Polyline bulge values are preserved.
- Per-vertex widths are scaled and preserved where present.
- ARC angles from dxf-parser are converted from radians back to DXF degrees before writing.
- Basic LTYPE and LAYER tables are emitted.
- EXTMIN/EXTMAX header values are emitted.
- Generated coordinates are millimetres.

MANDATORY RELEASE GATE
Before a generated DXF can be stored/downloaded, MERLIN reparses it and requires:
1. parse succeeds;
2. output width/height match calculated dimensions within 0.08 mm;
3. entity count matches source;
4. closed contour count matches source;
5. open contour state matches source;
6. no unsupported output entity appears.
Failure of any gate means no downloadable file is released.
